# 周慧敏經典情歌・男聲全新編曲伴奏包

為男聲練習／自彈自唱而做嘅**全新編曲伴奏**（原創和弦床＋節奏／織體），氣氛向 90 年代粵語流行慢板／中板致敬，**唔係**翻錄官方卡拉 OK，亦**唔會**重現受版權保護嘅原曲旋律線。

適合：男聲翻唱練習、 rehearsing 音域、錄 demo 底床。

---

## 點樣用

1. 打開 `mp3/`（或 `wav/` 更高質）對住自己想唱嗰首氣氛接近嘅曲目練習。
2. 跟住下面「建議調」唱；若仍偏高／偏低，可用任何 DAW／卡拉 OK App 再 ±1–2 個半音。
3. 結構大致：Intro → Verse →（Pre）→ Chorus → … → Bridge → Final Chorus → Outro。入歌前聽 4–8 小節 intro 再起聲。

## 男聲音域小貼士

- 周慧敏原唱多屬偏高女中／女高；男聲通常 **降 3–5 個半音** 最自然（業界《最愛》男調常見 **-4**）。
- 寧選可以輕鬆唱到副歌高潮、唔使全程吼嘅調。
- 慢板曲（最愛／心軟）用胸聲為主；中板（從今開始）可混聲帶動。

```bash

python3 scripts/generate_male_accompaniment.py
```
