# Cursor output

呢個資料夾係 **Vibe Coding Area** 入面畀 Cursor Agent 放 deliverable 嘅預設位置。

- Cloud / IDE Agent 產生嘅筆記、報告、CSV、圖表、知識庫等，應寫入呢度（或下面嘅主題子資料夾）。
- 本地打開呢個 repo／folder，pull／merge 之後就可以直接睇。
- 規則檔：`.cursor/rules/cursor-output-local-sync.mdc`（`alwaysApply: true`，之後其他 agent 都會跟）。

## 現有內容

| 路徑 | 說明 |
|------|------|
| `YouTube知識筆記/` | YouTube 健康知識筆記（可撳時間戳跳片） |
| `report/`、`*candidates.csv`、`*charts/` 等 | 市場／crypto 掃描輸出 |
| `報告/` | 每日持倉盈虧快照（HKT） |
