# 蟲草蒸雞醃料與蒸煮指南

份量：半隻雞（約 500 克）

## 基本醃料

| 材料 | 份量 | 用途 |
| --- | --- | --- |
| 生抽（醬油） | 1 湯匙 | 提供鹹鮮味 |
| 蠔油 | 1 湯匙 | 提鮮、上色 |
| 紹興花雕酒 | 1 湯匙 | 去腥增香 |
| 鹽 | ½ 茶匙 | 打底鹹味 |
| 糖 | ½ 茶匙 | 提鮮、中和鹹味 |
| 生粉（玉米澱粉） | 1 湯匙 | 鎖住肉汁，令雞肉嫩滑 |
| 麻油 | 1 茶匙 | 最後加入，包覆醬汁 |
| 胡椒粉 | 少許 | 增香 |

## 配料

- 蟲草花：快速沖洗後浸軟 5–10 分鐘，瀝乾。
- 可按喜好加入紅棗絲、杞子及薑絲。

## 醃製方法

1. 雞肉洗淨後徹底吸乾水分。
2. 先加入生抽、蠔油、花雕酒、鹽、糖及胡椒粉，抓拌至醃料被雞肉吸收。
3. 加入生粉拌勻。
4. 最後加入麻油，包覆醬汁及鎖住水分。
5. 醃最少 20–30 分鐘；時間充足可更入味。

## 蒸煮

1. 蒸前把已瀝乾的蟲草花，以及紅棗絲、杞子和薑絲拌入雞肉。
2. 水滾後才放入蒸鍋，以大火蒸 12–15 分鐘，按雞件大小調整。
3. 關火後焗 2 分鐘，再取出享用；口感會較嫩滑。
