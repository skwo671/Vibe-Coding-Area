# 三杯雞扒菇

雞腿扒炒杏鮑菇／雜菇，菇類吸收三杯醬汁及雞油香，適合配飯。

## 食材

| 食材／配料 | 建議份量 |
| --- | --- |
| 雞腿扒 | 2 塊，切一口大小 |
| 杏鮑菇 | 2–3 隻，切塊或滾刀塊 |
| 九層塔（羅勒） | 1 大把 |
| 老薑 | 8–10 片 |
| 蒜頭 | 8–10 粒，整粒拍扁 |
| 紅辣椒 | 1 隻，切斜片；可省略 |

## 三杯醬汁

| 材料 | 份量 |
| --- | --- |
| 黑麻油 | 1.5 湯匙 |
| 米酒／花雕酒 | 2 湯匙 |
| 醬油（生抽） | 1.5 湯匙 |
| 老抽 | ½ 茶匙 |
| 冰糖／白糖 | 1 茶匙 |

## 做法

1. **乾炒菇類：** 白鑊不放油，下杏鮑菇以中火炒至表面微黃、釋放水分及散發菇香，盛起備用。
2. **煎香雞扒：** 雞皮朝下，以中火煎出雞油；煎至兩面金黃、約 7–8 成熟，盛起備用。
3. **爆香香料：** 利用鑊中雞油，加入黑麻油。下薑片以小火慢煸至邊緣微捲，再加蒜頭炒至金黃。
4. **收汁：** 回鑊加入雞肉及杏鮑菇，倒入米酒、醬油、老抽和冰糖，以大火炒勻。蓋上鍋蓋，轉小火煮 3–5 分鐘，至醬汁濃稠收乾。
5. **提香：** 關火前加入紅辣椒和九層塔，快速炒兩下；蓋上鍋蓋並熄火焗 30 秒，即可上碟。

## 重點

- 先乾炒菇類，可減少出水、提升菇香，亦更能吸收醬汁。
- 雞扒先煎至 7–8 成熟即可，最後收汁時完成熟度，避免肉質過熟。
